Bài 2: CSS Cơ Bản

Thời gian học: ~20 phút

1. CSS là gì?

CSS (Cascading Style Sheets) là ngôn ngữ định dạng giao diện cho trang web.

CSS giúp thay đổi màu sắc, kích thước, vị trí, bố cục của các phần tử HTML.

2. Ba cách thêm CSS

2.1 Inline CSS (Trong thẻ HTML)

<p style="color: red; font-size: 20px;">
    Văn bản đỏ
</p>

2.2 Internal CSS (Trong thẻ <style>)

<head>
    <style>
        p {
            color: blue;
            font-size: 18px;
        }
    </style>
</head>

2.3 External CSS (File riêng)

<!-- Trong file HTML -->
<head>
    <link rel="stylesheet" href="style.css">
</head>

/* Trong file style.css */
p {
    color: green;
}
Khuyến nghị: Sử dụng External CSS cho dự án thực tế để code sạch và dễ bảo trì!

3. Cú pháp CSS

selector {
    property: value;
    property2: value2;
}

/* Ví dụ thực tế */
h1 {
    color: blue;
    font-size: 32px;
    text-align: center;
}

4. CSS Selectors (Bộ chọn)

4.1 Element Selector

/* Chọn tất cả thẻ p */
p {
    color: red;
}

/* Chọn tất cả thẻ h1 */
h1 {
    font-size: 24px;
}

4.2 Class Selector (.)

/* CSS */
.highlight {
    background-color: yellow;
}

.text-red {
    color: red;
}

<!-- HTML -->
<p class="highlight">Được highlight</p>
<p class="text-red highlight">Đỏ và highlight</p>

4.3 ID Selector (#)

/* CSS */
#header {
    background: #333;
    color: white;
}

<!-- HTML -->
<div id="header">Header duy nhất</div>
Ghi nhớ:
  • class - Có thể dùng nhiều lần, chọn bằng dấu chấm (.)
  • id - Chỉ dùng 1 lần trên trang, chọn bằng dấu thăng (#)

5. Các thuộc tính CSS phổ biến

5.1 Màu sắc

/* Tên màu */
color: red;
color: blue;

/* Mã HEX */
color: #ff0000;  /* Đỏ */
color: #00ff00;  /* Xanh lá */
color: #0000ff;  /* Xanh dương */

/* RGB */
color: rgb(255, 0, 0);

/* RGBA (có độ trong suốt) */
color: rgba(255, 0, 0, 0.5);

5.2 Font chữ

p {
    font-family: Arial, sans-serif;
    font-size: 16px;
    font-weight: bold;  /* normal, bold, 100-900 */
    font-style: italic;
    text-align: center;  /* left, right, center, justify */
    text-decoration: underline;  /* none, underline, line-through */
    line-height: 1.5;
}

5.3 Background

div {
    background-color: #f0f0f0;
    background-image: url('image.jpg');
    background-size: cover;  /* cover, contain, 100px */
    background-position: center;
    background-repeat: no-repeat;
}

5.4 Kích thước

div {
    width: 300px;
    height: 200px;
    max-width: 100%;
    min-height: 50px;
}

/* Đơn vị thường dùng */
/* px - pixel (cố định) */
/* % - phần trăm theo phần tử cha */
/* em - theo font-size phần tử cha */
/* rem - theo font-size root (html) */
/* vh/vw - % viewport height/width */

6. Box Model (Mô hình hộp)

Mọi phần tử HTML đều là một "hộp" với 4 phần:

  • Content - Nội dung bên trong
  • Padding - Khoảng đệm (trong border)
  • Border - Viền
  • Margin - Khoảng cách ngoài

div {
    /* Padding */
    padding: 20px;  /* Tất cả các cạnh */
    padding: 10px 20px;  /* Trên/dưới Trái/phải */
    padding: 10px 20px 15px 25px;  /* Trên Phải Dưới Trái */
    padding-top: 10px;
    padding-right: 20px;

    /* Margin */
    margin: 20px;
    margin: 0 auto;  /* Căn giữa */

    /* Border */
    border: 2px solid #333;
    border-radius: 10px;  /* Bo góc */
}

7. Display

/* Block - Chiếm cả dòng */
display: block;

/* Inline - Trên cùng dòng, không đặt width/height */
display: inline;

/* Inline-block - Trên cùng dòng, đặt được width/height */
display: inline-block;

/* None - Ẩn phần tử */
display: none;

/* Flex - Layout linh hoạt (học ở bài sau) */
display: flex;
